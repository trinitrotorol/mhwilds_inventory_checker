# Decisions

- Keep originals untouched and use fresh isolated clones for both repositories.
- Retain existing Python/TypeScript solver architecture and worker termination.
- Keep remote compute disabled by default: free-tier allowances and budget alerts
  alone cannot guarantee no additional charges.
- Preserve explicit appraisal instances; export only anonymous search constraints.
- Use a shared versioned localStorage key with guarded writes and Web Locks when
  available; do not claim transactional guarantees for unsupported browsers.
- Existing source assumes exactly seven equipment parts including a charm; retain
  that contract until a deliberate tested no-charm extension is required.

# UIデザイン方針

2026-10-06の追加指定により、両アプリはデジタル庁デザインシステムを参考にした
白地・青の操作色・明確な余白を用いる。以前の緑・金の配色は更新した。
これは独立したゲーム用サービスの独自実装であり、行政機関の公式サービスや
デザインシステムへの完全準拠を表明するものではない。

参照資料（確認日2026-10-06、公開版v2.18.0）：

- [カラー](https://design.digital.go.jp/dads/foundations/color/)
- [タイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/)
- [ボタン](https://design.digital.go.jp/dads/components/button/)
- [インプットテキスト](https://design.digital.go.jp/dads/components/input-text/)

本文・入力・ボタンは16pxを基準とし、補助情報も14px未満にしない。
OSにあるサンセリフ体を使い、外部Webフォントは読込まない。通常文字は黒、
補足は濃いグレー、リンクと主要操作は青で表す。成功・警告・エラーは色と文言を
併用する。フォーカスは黄色と黒の二重表示で、操作領域は44px以上を保つ。

主操作は青塗り、副操作は枠線、取消などは文脈に応じたテキスト操作とする。
入力には常時ラベルを付け、エラーを近くに表示して関連付ける。
スキップリンク、見出し順序、カテゴリの現在位置、native dialogの
フォーカス管理を用いる。狭い画面では列を自然に縦へ並べ、横はみ出しを隠さない。

自動アクセシビリティ検査と各viewportの視覚確認はリリース記録の実行結果を参照する。
